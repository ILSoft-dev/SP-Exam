<div class="tldr" markdown="1">
**Атрибуты файла** хранятся в **inode** и доступны через **`stat`/`fstat`/`lstat`** (структура `struct stat`): тип и права (`st_mode`), номер inode (`st_ino`), устройство (`st_dev`), число жёстких ссылок (`st_nlink`), владелец и группа (`st_uid`, `st_gid`), размер (`st_size`), число блоков, **времена**: `st_atime` (доступ), `st_mtime` (изменение данных), `st_ctime` (изменение inode). **Имени файла в inode нет** — оно хранится в каталоге.

**Управление свойствами:** `chmod`, `chown`, `utime`/`utimensat` (времена), `truncate`, `rename`, `link`/`unlink`.

**Работа с файлами** через **файловые дескрипторы** (0 — stdin, 1 — stdout, 2 — stderr): `open`, `read`, `write`, `lseek`, `close`, `dup`/`dup2`, `fcntl`, `fsync`, `mmap`. Каталоги: `mkdir`, `rmdir`, `opendir`/`readdir`, `chdir`, `getcwd`.

**Структура ФС (s5fs / ext2):** загрузочный блок → **суперблок** (параметры ФС, списки свободных блоков и inode) → **таблица (массив) inode** → **блоки данных**. В ext2/3/4 диск делится на **группы блоков** с битовыми картами. Единое **дерево каталогов** от корня `/`, другие ФС **монтируются**. **VFS** даёт единый интерфейс для разных ФС.
</div>

## Атрибуты файла: struct stat

```c
#include <sys/stat.h>
#include <stdio.h>
#include <time.h>

int main(int argc, char *argv[]) {
    struct stat st;
    if (stat(argv[1], &st) == -1) { perror("stat"); return 1; }
    printf("inode:   %lu\n", (unsigned long)st.st_ino);
    printf("права:   %o\n", st.st_mode & 0777);
    printf("ссылок:  %lu\n", (unsigned long)st.st_nlink);
    printf("UID/GID: %d/%d\n", st.st_uid, st.st_gid);
    printf("размер:  %lld байт\n", (long long)st.st_size);
    printf("изменён: %s", ctime(&st.st_mtime));
    return 0;
}
```

| Поле | Смысл |
|---|---|
| `st_mode` | Тип файла + права (+ SUID, SGID, sticky) |
| `st_ino` | Номер inode |
| `st_dev` | Устройство, на котором находится файл |
| `st_nlink` | Число жёстких ссылок |
| `st_uid`, `st_gid` | Владелец и группа |
| `st_size` | Размер в байтах |
| `st_blocks`, `st_blksize` | Занято блоков, оптимальный размер блока ввода-вывода |
| `st_atime` | Время последнего **доступа** (чтения) |
| `st_mtime` | Время последнего **изменения содержимого** |
| `st_ctime` | Время последнего **изменения inode** (прав, владельца, ссылок). Это **не** время создания |

Команды: `stat file`, `ls -li` (с номерами inode), `touch` (меняет времена).

## Управление свойствами файлов

| Задача | Вызов | Команда |
|---|---|---|
| Права | `chmod`, `fchmod` | `chmod` |
| Владелец и группа | `chown`, `fchown`, `lchown` | `chown`, `chgrp` |
| Времена | `utime`, `utimes`, `utimensat` | `touch` |
| Размер | `truncate`, `ftruncate` | `truncate` |
| Переименование и перемещение | `rename` | `mv` |
| Жёсткая и символическая ссылка | `link`, `symlink`, `readlink` | `ln`, `ln -s` |
| Удаление имени | `unlink` | `rm` |
| Маска прав | `umask` | `umask` |

**Особенность `unlink`:** удаляется **имя** (запись в каталоге), `st_nlink` уменьшается. Данные освобождаются, когда счётчик ссылок станет 0 **и** файл не открыт ни одним процессом. Поэтому можно открыть временный файл и сразу вызвать `unlink`: он исчезнет автоматически при закрытии.

## Работа с файлами

### Файловые дескрипторы

<pre class="diagram">
Процесс                 Ядро
таблица дескрипторов    таблица открытых     таблица
                        файлов (общая)       inode
 0 ─────────────────►  [режим, позиция] ──► [inode tty]
 1 ─────────────────►  [ ... ]
 3 ─────────────────►  [O_RDONLY, pos=100]─► [inode a.txt]
 4 ──┘ (dup)
</pre>

- **Дескриптор** — небольшое целое число, индекс в таблице открытых файлов процесса. 0, 1, 2 — стандартные **ввод, вывод, ошибки**.
- Запись в **системной таблице открытых файлов** хранит режим открытия и **текущую позицию**. Она разделяется после `fork` и `dup`.
- **Таблица inode в памяти** — одна запись на файл.

### Основные вызовы

```c
int fd = open("log.txt", O_WRONLY | O_CREAT | O_APPEND, 0644);
write(fd, "hello\n", 6);
lseek(fd, 0, SEEK_SET);          // позиция: SEEK_SET, SEEK_CUR, SEEK_END
close(fd);
```

| Вызов | Назначение |
|---|---|
| `open(path, flags, mode)` | Открыть или создать. Флаги: `O_RDONLY`, `O_WRONLY`, `O_RDWR`, `O_CREAT`, `O_EXCL`, `O_TRUNC`, `O_APPEND`, `O_NONBLOCK`, `O_SYNC` |
| `creat(path, mode)` | То же, что `open` с флагами `O_WRONLY`, `O_CREAT`, `O_TRUNC` |
| `read(fd, buf, n)` | Возвращает число прочитанных байтов, **0 — конец файла**, −1 — ошибка |
| `write(fd, buf, n)` | Число записанных байтов |
| `lseek(fd, off, whence)` | Сменить позицию. Можно выйти за конец — получится «дыра» (sparse file) |
| `close(fd)` | Закрыть |
| `dup(fd)`, `dup2(fd, newfd)` | Дублировать дескриптор (перенаправление ввода-вывода) |
| `fcntl(fd, cmd, ...)` | Флаги дескриптора, **блокировки записей** (`F_SETLK`) |
| `fsync(fd)` | Принудительно записать данные на диск |
| `mmap` | Отобразить файл в память |
| `pread`/`pwrite` | Чтение и запись по смещению без изменения позиции |

**Перенаправление вывода в файл** (как `prog > out.txt`):
```c
int fd = open("out.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
dup2(fd, 1);        // теперь stdout → out.txt
close(fd);
execlp("ls", "ls", "-l", NULL);
```

### Работа с каталогами

```c
#include <dirent.h>
DIR *d = opendir(".");
struct dirent *e;
while ((e = readdir(d)) != NULL)
    printf("%lu  %s\n", (unsigned long)e->d_ino, e->d_name);
closedir(d);
```

Также: `mkdir(path, mode)`, `rmdir` (только пустой), `chdir`, `getcwd`, `nftw` (обход дерева).

## Структура файловой системы

### Классическая ФС UNIX (s5fs)

<pre class="diagram">
┌──────┬───────────┬──────────────┬────────────────┐
│Загр. │ Суперблок │ Массив inode │ Блоки данных   │
│ блок │           │              │                │
└──────┴───────────┴──────────────┴────────────────┘
</pre>

- **Загрузочный блок** — код начальной загрузки.
- **Суперблок** — параметры ФС: размер, число inode и блоков, **списки свободных блоков и inode**, флаги состояния.
- **Массив inode** — фиксированное число индексных дескрипторов. Количество файлов ограничено числом inode (`df -i`).
- **Блоки данных** — содержимое файлов и каталогов.

### ext2/ext3/ext4

- Диск делится на **группы блоков**. В каждой группе: копия суперблока (в части групп), дескрипторы групп, **битовая карта блоков**, **битовая карта inode**, **таблица inode**, блоки данных. Связанные данные лежат рядом, меньше перемещений головки.
- **inode:** атрибуты + 12 прямых, косвенный, двойной и тройной косвенный блоки. ext4 использует **экстенты**.
- ext3 и ext4 — **журналируемые**.

### Каталог

Каталог — файл со списком записей **«имя → номер inode»**. В каждом каталоге есть `.` (сам каталог) и `..` (родитель). Поиск файла `/home/ivan/a.txt`: inode корня (№ 2) → блоки каталога `/` → найти `home` → его inode → найти `ivan` → … → inode `a.txt`.

### Дерево каталогов и монтирование

- Единое дерево от корня **`/`**: `/bin`, `/etc` (конфигурация), `/home`, `/dev` (устройства), `/proc` (информация о процессах), `/tmp`, `/usr`, `/var` (журналы, данные). Стандарт **FHS**.
- Другие ФС **монтируются** в каталоги: `mount /dev/sdb1 /mnt/usb`, `/etc/fstab`, вызов `mount()`.
- **VFS (виртуальная файловая система)** — слой ядра с единым интерфейсом (vnode/inode, file, dentry, superblock) для ext4, XFS, NFS, FAT, `/proc`.
