<div class="tldr" markdown="1">
**Стандарты UNIX:**
- **SVID** (System V Interface Definition, AT&T);
- **POSIX** (IEEE 1003, «переносимый интерфейс ОС»: системные вызовы, оболочка, утилиты, потоки `pthreads`);
- **X/Open XPG**, **Single UNIX Specification (SUS)** — сертификация «UNIX»;
- стандарт языка **ANSI/ISO C**.

Ветви: **System V** и **BSD**, сегодня Linux, FreeBSD, macOS, Solaris.

**Пользователь** описывается атрибутами: **имя (login)**, **UID**, **GID** основной группы, дополнительные группы, домашний каталог, командная оболочка, пароль. Хранятся в `/etc/passwd`, `/etc/shadow`, `/etc/group`. **root** (UID 0) — суперпользователь.

**Создание программы:** исходный текст на C + **заголовочные файлы** (`<unistd.h>`, `<fcntl.h>`, `<sys/types.h>`) → `gcc prog.c -o prog` (препроцессор → компилятор → ассемблер → компоновщик).

**Системные вызовы** (`open`, `read`, `fork`) выполняются ядром. **Библиотечные функции** (`printf`, `fopen`, `malloc`) работают в пользовательском режиме и при необходимости сами делают системные вызовы.

**Ошибки:** системный вызов возвращает **−1** и записывает код в **`errno`**. Текст ошибки дают `perror()` и `strerror()`.

**Форматы выполняемых файлов:** **a.out**, **COFF**, **ELF** (современный стандарт).

## Стандарты UNIX

| Стандарт | Кто | Что определяет |
|---|---|---|
| **SVID** | AT&T (System V) | Интерфейс System V: IPC (сообщения, семафоры, разделяемая память) |
| **BSD** | Беркли | Сокеты, расширенная ФС, виртуальная память |
| **POSIX** (IEEE 1003.1, 1988 и далее) | IEEE, ISO/IEC 9945 | **Системные вызовы и функции** (1003.1), оболочка и утилиты (1003.2), реальное время (1003.1b), **потоки pthreads** (1003.1c) |
| **X/Open XPG**, **SUS** (Single UNIX Specification) | The Open Group | Надмножество POSIX. Право называться «UNIX» |
| **ANSI C / ISO C** | ANSI, ISO | Язык и стандартная библиотека (`stdio.h`, `stdlib.h`, `string.h`) |
| **LSB** | Linux Foundation | Двоичная совместимость дистрибутивов Linux |

Проверить поддержку в программе можно макросами (`_POSIX_VERSION`) и вызовами `sysconf()`, `pathconf()`.

## Пользователи и их атрибуты

```text
/etc/passwd:
ivan:x:1001:1001:Иван Петров:/home/ivan:/bin/bash
 │   │  │    │       │           │         └─ оболочка
 │   │  │    │       │           └─ домашний каталог
 │   │  │    │       └─ комментарий (GECOS)
 │   │  │    └─ GID основной группы
 │   │  └─ UID
 │   └─ пароль (x — хранится в /etc/shadow)
 └─ имя входа
```

- **UID / GID** — числовые идентификаторы пользователя и группы. Именно их ядро использует для проверки прав.
- **root (UID 0)** — суперпользователь, проверки прав для него не выполняются.
- У процесса: **реальные** (RUID, RGID) — кто запустил; **эффективные** (EUID, EGID) — с какими правами работает (отличаются при SUID/SGID); **сохранённые** идентификаторы.
- Команды: `id`, `whoami`, `useradd`, `passwd`, `groups`, `su`, `sudo`.
- Вызовы: `getuid()`, `geteuid()`, `getgid()`, `getpwnam()`, `getpwuid()`, `setuid()`.

```c
#include <stdio.h>
#include <unistd.h>
#include <pwd.h>

int main(void) {
    struct passwd *pw = getpwuid(getuid());
    printf("UID=%d EUID=%d login=%s home=%s\n",
           getuid(), geteuid(), pw->pw_name, pw->pw_dir);
    return 0;
}
```

## Создание программы

**Исходный текст + заголовки:**

```c
/* copy.c — копирование файла системными вызовами */
#include <fcntl.h>      /* open, O_RDONLY ... */
#include <unistd.h>     /* read, write, close */
#include <stdio.h>      /* perror */
#include <stdlib.h>     /* exit */

int main(int argc, char *argv[]) {
    if (argc != 3) { fprintf(stderr, "usage: %s src dst\n", argv[0]); exit(1); }
    int in = open(argv[1], O_RDONLY);
    if (in == -1) { perror("open src"); exit(1); }
    int out = open(argv[2], O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (out == -1) { perror("open dst"); exit(1); }
    char buf[4096]; ssize_t n;
    while ((n = read(in, buf, sizeof buf)) > 0)
        if (write(out, buf, n) != n) { perror("write"); exit(1); }
    if (n == -1) perror("read");
    close(in); close(out);
    return 0;
}
```

**Сборка:**

```bash
gcc -Wall -o copy copy.c      # препроцессор → компиляция → ассемблер → компоновка
./copy a.txt b.txt
gcc -c util.c                 # только объектный файл util.o
gcc main.o util.o -o app -lm  # компоновка с библиотекой libm
```

Этапы: **препроцессор** (`cpp`: `#include`, `#define`) → **компилятор** (`cc1`: C → ассемблер) → **ассемблер** (`as`: → объектный `.o`) → **компоновщик** (`ld`: объектные файлы + библиотеки → исполняемый файл). Для больших проектов используется **make** (`Makefile`).

**Аргументы и окружение:** `int main(int argc, char *argv[], char *envp[])`, а также `getenv()`, `setenv()`. Код завершения возвращается через `return` или `exit()`.

## Системные вызовы и функции стандартных библиотек

| | Системный вызов | Библиотечная функция |
|---|---|---|
| Где выполняется | В **ядре** (переход в режим ядра через `syscall`) | В **пользовательском режиме**, в библиотеке (`libc`) |
| Пример | `open`, `read`, `write`, `fork`, `exec`, `brk`, `mmap` | `fopen`, `fprintf`, `fgets`, `malloc`, `strlen`, `qsort` |
| Стоимость | Дорого (переключение режима) | Дёшево (обычный вызов функции) |
| Буферизация | Нет | `stdio` буферизует ввод-вывод |
| Раздел man | **2** (`man 2 read`) | **3** (`man 3 fopen`) |

Многие функции библиотеки — **обёртки** над системными вызовами: `fopen` вызывает `open`, `printf` в итоге вызывает `write`, `malloc` вызывает `brk` или `mmap`. Увидеть вызовы программы можно командой `strace ./prog`.

## Обработка ошибок

- Системные вызовы при ошибке обычно возвращают **−1** (или `NULL` для функций с указателями) и записывают код ошибки в глобальную (для каждого потока своя) переменную **`errno`** (`<errno.h>`).
- Коды: `ENOENT` (нет файла), `EACCES` (нет прав), `EEXIST`, `EINTR` (прерван сигналом), `ENOMEM`, `EBADF` (неверный дескриптор), `EAGAIN`.
- `errno` **не сбрасывается** при успехе, поэтому проверять его можно только после неудачного вызова.

```c
#include <errno.h>
#include <string.h>

int fd = open("nofile.txt", O_RDONLY);
if (fd == -1) {
    perror("open");                              /* open: No such file or directory */
    fprintf(stderr, "ошибка %d: %s\n", errno, strerror(errno));
    if (errno == ENOENT) { /* создать файл */ }
}
```

- Функции `pthread_*` возвращают код ошибки напрямую, а не через `errno`.
- **Хороший стиль:** проверять результат **каждого** системного вызова.

## Форматы выполняемых файлов

| Формат | Где | Особенности |
|---|---|---|
| **a.out** | Ранние UNIX | Простой: заголовок, код (text), данные, таблица символов. Не поддерживает разделяемые библиотеки удобно |
| **COFF** | System V, ранние Windows (основа PE) | Секции, отладочная информация |
| **ELF** (Executable and Linkable Format) | **Linux**, BSD, Solaris, Android | Стандарт де-факто. Исполняемые файлы, объектные (`.o`), разделяемые библиотеки (`.so`), дампы памяти (core) |
| **Mach-O** | macOS, iOS | |
| **PE/COFF** | Windows (`.exe`, `.dll`) | [Вопрос 32]({{ '/q/32.html' | relative_url }}) |
