<div class="tldr" markdown="1">
**Вывод графики** выполняется функциями GDI через **контекст устройства**:
- **точки** — `SetPixel`;
- **линии и кривые** — `MoveToEx`/`LineTo`, `Polyline`, `PolyBezier`, `Arc`;
- **замкнутые фигуры** — `Rectangle`, `RoundRect`, `Ellipse`, `Pie`, `Chord`, `Polygon`;
- **текст** — `TextOut`, `DrawText`, `ExtTextOut`;
- **растры** — `BitBlt`, `StretchBlt`, `TransparentBlt`, `AlphaBlend`, `SetDIBitsToDevice`;
- **заливка** — `FillRect`, `FloodFill`, `FillRgn`.

**Графические инструменты (объекты GDI):**
- **перо** (`HPEN`) — линии и контуры;
- **кисть** (`HBRUSH`) — заливка внутренней области;
- **шрифт** (`HFONT`);
- **растр** (`HBITMAP`);
- **палитра** (`HPALETTE`);
- **регион** (`HRGN`).

Порядок работы: **создать** (`CreatePen`, `CreateSolidBrush`, `CreateFont`…) или взять **стандартный** (`GetStockObject`) → **выбрать** в DC (`SelectObject`, сохранив старый) → **рисовать** → **вернуть старый** объект → **удалить** свой (`DeleteObject`).

Для вывода без мерцания используется **двойная буферизация**: рисование в DC памяти и копирование на экран через `BitBlt`. Печать — тот же GDI с DC принтера (`StartDoc`/`StartPage`/`EndPage`/`EndDoc`).
</div>

## Функции вывода

### Линии и кривые (рисуются текущим пером)

```c
MoveToEx(hdc, 10, 10, NULL);   // переместить текущую позицию
LineTo(hdc, 200, 10);          // линия до точки (конечная точка не рисуется)
POINT pts[] = { {10,50}, {60,100}, {110,50}, {160,100} };
Polyline(hdc, pts, 4);         // ломаная
PolyBezier(hdc, pts, 4);       // кривая Безье (1 + 3n точек)
Arc(hdc, 10, 120, 110, 220, 110, 170, 10, 170);   // дуга эллипса
SetPixel(hdc, 5, 5, RGB(255, 0, 0));              // точка
```

### Замкнутые фигуры (контур — пером, заливка — кистью)

```c
Rectangle(hdc, 10, 10, 110, 60);                // прямоугольник
RoundRect(hdc, 120, 10, 220, 60, 20, 20);       // со скруглёнными углами
Ellipse(hdc, 10, 70, 110, 130);                 // эллипс, вписанный в прямоугольник
Pie(hdc, 120, 70, 220, 170, 220, 120, 170, 70); // сектор
Chord(...);                                      // сегмент
POINT tri[] = { {50,150}, {100,230}, {0,230} };
Polygon(hdc, tri, 3);                            // многоугольник
FillRect(hdc, &rc, hBrush);                      // заливка без контура
FrameRect(hdc, &rc, hBrush);                     // только рамка
```

### Текст

```c
SetTextColor(hdc, RGB(0, 0, 128));
SetBkMode(hdc, TRANSPARENT);                    // без фона под буквами
TextOutW(hdc, 10, 10, L"Строка", 6);
RECT rc = { 0, 0, 300, 100 };
DrawTextW(hdc, L"По центру", -1, &rc, DT_CENTER | DT_VCENTER | DT_SINGLELINE);
SIZE sz; GetTextExtentPoint32W(hdc, L"Строка", 6, &sz);   // размер текста
TEXTMETRICW tm; GetTextMetricsW(hdc, &tm);               // метрики шрифта
```

### Растровые изображения

```c
HBITMAP hbm = (HBITMAP)LoadImageW(NULL, L"pic.bmp", IMAGE_BITMAP, 0, 0, LR_LOADFROMFILE);
HDC mem = CreateCompatibleDC(hdc);
HBITMAP old = (HBITMAP)SelectObject(mem, hbm);
BITMAP bm; GetObject(hbm, sizeof bm, &bm);
BitBlt(hdc, 10, 10, bm.bmWidth, bm.bmHeight, mem, 0, 0, SRCCOPY);       // 1:1
StretchBlt(hdc, 0, 0, 400, 300, mem, 0, 0, bm.bmWidth, bm.bmHeight, SRCCOPY); // масштаб
SelectObject(mem, old); DeleteDC(mem); DeleteObject(hbm);
```

- **Растровые операции (ROP):** `SRCCOPY`, `SRCAND`, `SRCPAINT`, `SRCINVERT` (XOR), `NOTSRCCOPY`. С их помощью делают маски и прозрачность.
- **DDB** (аппаратно-зависимый растр, `HBITMAP`) и **DIB** (аппаратно-независимый, формат `.bmp`: `BITMAPINFOHEADER` + пиксели). Функции для DIB: `CreateDIBSection`, `StretchDIBits`, `SetDIBitsToDevice`.
- `TransparentBlt` (прозрачный цвет), `AlphaBlend` (полупрозрачность), `PatBlt` (заливка кистью).

## Графические инструменты (объекты GDI)

| Инструмент | Создание | Стандартные (`GetStockObject`) | Влияет на |
|---|---|---|---|
| **Перо** `HPEN` | `CreatePen(стиль, толщина, цвет)`, `ExtCreatePen`. Стили: `PS_SOLID`, `PS_DASH`, `PS_DOT`, `PS_DASHDOT`, `PS_NULL` | `BLACK_PEN`, `WHITE_PEN`, `NULL_PEN`, `DC_PEN` | Линии и контуры фигур |
| **Кисть** `HBRUSH` | `CreateSolidBrush(цвет)`, `CreateHatchBrush(HS_CROSS…, цвет)`, `CreatePatternBrush(растр)` | `WHITE_BRUSH`, `GRAY_BRUSH`, `BLACK_BRUSH`, `NULL_BRUSH` (без заливки), `DC_BRUSH` | Заливка фигур и фона |
| **Шрифт** `HFONT` | `CreateFont(...)`, `CreateFontIndirect(&LOGFONT)` | `SYSTEM_FONT`, `DEFAULT_GUI_FONT`, `ANSI_FIXED_FONT` | Текст |
| **Растр** `HBITMAP` | `CreateBitmap`, `CreateCompatibleBitmap`, `LoadImage`, `CreateDIBSection` | — | Поверхность DC памяти |
| **Палитра** `HPALETTE` | `CreatePalette` | `DEFAULT_PALETTE` | Цвета на 256-цветных устройствах (сейчас почти не нужна) |
| **Регион** `HRGN` | `CreateRectRgn`, `CreateEllipticRgn`, `CreatePolygonRgn`, `CombineRgn` | — | Отсечение (`SelectClipRgn`), заливка, форма окна (`SetWindowRgn`), проверка попадания (`PtInRegion`) |

**Цвет** задаётся макросом `RGB(r, g, b)` (тип `COLORREF`).

### Жизненный цикл объекта

```c
HBRUSH br  = CreateHatchBrush(HS_DIAGCROSS, RGB(0, 128, 0));   // 1. создать
HPEN   pen = CreatePen(PS_DASH, 1, RGB(0, 0, 255));
HBRUSH oldBr  = (HBRUSH)SelectObject(hdc, br);                  // 2. выбрать
HPEN   oldPen = (HPEN)SelectObject(hdc, pen);
Ellipse(hdc, 20, 20, 220, 140);                                 // 3. рисовать
SelectObject(hdc, oldBr);                                       // 4. вернуть
SelectObject(hdc, oldPen);
DeleteObject(br);                                               // 5. удалить
DeleteObject(pen);
```

**Шрифт:**
```c
LOGFONTW lf = {0};
lf.lfHeight = -MulDiv(14, GetDeviceCaps(hdc, LOGPIXELSY), 72);   // 14 пунктов
lf.lfWeight = FW_BOLD;
lf.lfCharSet = DEFAULT_CHARSET;
wcscpy_s(lf.lfFaceName, LF_FACESIZE, L"Segoe UI");
HFONT f = CreateFontIndirectW(&lf);
HFONT old = (HFONT)SelectObject(hdc, f);
TextOutW(hdc, 10, 10, L"Жирный шрифт", 12);
SelectObject(hdc, old); DeleteObject(f);
```

<div class="tip" markdown="1">
**Стандартные объекты** (`GetStockObject`) удалять не нужно. Свои объекты удаляются **только после того, как в DC выбран другой**. Количество объектов GDI видно в Диспетчере задач (столбец «Объекты GDI»), их утечка — частая ошибка.
</div>

## Двойная буферизация (без мерцания)

Если рисовать много фигур прямо на экране, пользователь видит промежуточные состояния. Решение: рисовать **в памяти**, а затем одним `BitBlt` копировать готовый кадр.

```c
case WM_PAINT: {
    PAINTSTRUCT ps; HDC hdc = BeginPaint(hwnd, &ps);
    RECT rc; GetClientRect(hwnd, &rc);
    HDC mem = CreateCompatibleDC(hdc);
    HBITMAP bmp = CreateCompatibleBitmap(hdc, rc.right, rc.bottom);
    HBITMAP old = (HBITMAP)SelectObject(mem, bmp);

    FillRect(mem, &rc, (HBRUSH)GetStockObject(WHITE_BRUSH));
    DrawScene(mem);                                    // всё рисование — в mem

    BitBlt(hdc, 0, 0, rc.right, rc.bottom, mem, 0, 0, SRCCOPY);
    SelectObject(mem, old); DeleteObject(bmp); DeleteDC(mem);
    EndPaint(hwnd, &ps);
    return 0;
}
case WM_ERASEBKGND:
    return 1;      // фон стирать не нужно — меньше мерцания
```

## Вывод на принтер

Принтер — такое же устройство GDI:
```c
PRINTDLGW pd = { sizeof pd }; pd.Flags = PD_RETURNDC;
if (PrintDlgW(&pd)) {
    DOCINFOW di = { sizeof di, L"Мой документ" };
    StartDocW(pd.hDC, &di);
    StartPage(pd.hDC);
    TextOutW(pd.hDC, 100, 100, L"Печать через GDI", 16);
    EndPage(pd.hDC);
    EndDoc(pd.hDC);
    DeleteDC(pd.hDC);
}
```

Для одинакового размера на экране и бумаге используют режимы отображения (`MM_LOMETRIC`) или `GetDeviceCaps(LOGPIXELSX)`.
