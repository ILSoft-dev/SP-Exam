<div class="tldr" markdown="1">
Программа Windows с графическим интерфейсом **управляется событиями**: она не опрашивает клавиатуру и мышь, а получает **сообщения** от системы.

Основные элементы программы:
1. **`WinMain`** — точка входа.
2. **Класс окна** (`WNDCLASSEX`): оконная процедура, значок, курсор, кисть фона, имя класса. Регистрируется функцией `RegisterClassEx`.
3. **Создание окна** — `CreateWindowEx`, затем `ShowWindow` и `UpdateWindow`.
4. **Цикл обработки сообщений:** `GetMessage` → `TranslateMessage` → `DispatchMessage`.
5. **Оконная процедура** `WndProc(hwnd, msg, wParam, lParam)` — обрабатывает сообщения (`WM_PAINT`, `WM_DESTROY` …), остальные передаёт в `DefWindowProc`.

**Оконное сообщение** — уведомление окну о событии. Структура `MSG`: окно-получатель `hwnd`, код `message` (`WM_…`), параметры `wParam` и `lParam`, время, координаты курсора.

**Источники сообщений:**
- **пользователь** — клавиатура, мышь (через драйверы и систему);
- **система** — создание и изменение окна, перерисовка, таймер, завершение работы;
- **другие окна и программы** — `SendMessage`, `PostMessage`;
- **сама программа**;
- **элементы управления** — уведомления `WM_COMMAND`, `WM_NOTIFY`.
</div>

## Минимальная программа Win32

```c
#include <windows.h>

LRESULT CALLBACK WndProc(HWND hwnd, UINT msg, WPARAM wParam, LPARAM lParam) {
    switch (msg) {
    case WM_PAINT: {
        PAINTSTRUCT ps;
        HDC hdc = BeginPaint(hwnd, &ps);
        TextOutW(hdc, 20, 20, L"Привет, Windows!", 16);
        EndPaint(hwnd, &ps);
        return 0;
    }
    case WM_LBUTTONDOWN:
        MessageBoxW(hwnd, L"Щелчок мышью", L"Сообщение", MB_OK);
        return 0;
    case WM_DESTROY:
        PostQuitMessage(0);          // поместить WM_QUIT в очередь
        return 0;
    }
    return DefWindowProcW(hwnd, msg, wParam, lParam);   // обработка по умолчанию
}

int WINAPI wWinMain(HINSTANCE hInst, HINSTANCE hPrev, PWSTR cmd, int nShow) {
    WNDCLASSEXW wc = { sizeof wc };
    wc.lpfnWndProc   = WndProc;                    // оконная процедура
    wc.hInstance     = hInst;
    wc.hCursor       = LoadCursor(NULL, IDC_ARROW);
    wc.hIcon         = LoadIcon(NULL, IDI_APPLICATION);
    wc.hbrBackground = (HBRUSH)(COLOR_WINDOW + 1);
    wc.lpszClassName = L"MyWindowClass";
    RegisterClassExW(&wc);                         // 1. регистрация класса

    HWND hwnd = CreateWindowExW(0, L"MyWindowClass", L"Первое окно",
        WS_OVERLAPPEDWINDOW, CW_USEDEFAULT, CW_USEDEFAULT, 400, 300,
        NULL, NULL, hInst, NULL);                  // 2. создание окна
    ShowWindow(hwnd, nShow);                       // 3. показать
    UpdateWindow(hwnd);                            //    (сразу WM_PAINT)

    MSG msg;                                       // 4. цикл сообщений
    while (GetMessageW(&msg, NULL, 0, 0) > 0) {
        TranslateMessage(&msg);                    // WM_KEYDOWN → WM_CHAR
        DispatchMessageW(&msg);                    // вызвать WndProc окна
    }
    return (int)msg.wParam;
}
```

## Элементы программы подробно

### WinMain

- Параметры: `hInstance` — дескриптор экземпляра (адрес загрузки модуля), `hPrevInstance` — всегда NULL в Win32, командная строка, способ показа окна (`SW_SHOW…`).
- Соглашение о вызове `WINAPI` (`__stdcall`).

### Класс окна

Класс окна — **шаблон** для окон: все окна класса используют одну оконную процедуру.

| Поле `WNDCLASSEX` | Смысл |
|---|---|
| `lpfnWndProc` | Оконная процедура |
| `style` | `CS_HREDRAW`, `CS_VREDRAW` (перерисовка при изменении размера), `CS_DBLCLKS` (двойные щелчки) |
| `hIcon`, `hCursor` | Значок и курсор |
| `hbrBackground` | Кисть для фона |
| `lpszMenuName` | Меню из ресурсов |
| `lpszClassName` | Имя класса |

Есть **предопределённые классы** элементов управления: `BUTTON`, `EDIT`, `LISTBOX`, `COMBOBOX`, `STATIC`, `SCROLLBAR`.

### Создание окна

`CreateWindowEx(стиль_ex, класс, заголовок, стиль, x, y, ширина, высота, родитель, меню, экземпляр, параметр)`.
- Стили: `WS_OVERLAPPEDWINDOW` (обычное окно), `WS_CHILD`, `WS_VISIBLE`, `WS_POPUP`, `WS_BORDER`.
- Возвращает **дескриптор окна `HWND`**.
- Во время создания окно получает `WM_NCCREATE`, `WM_CREATE` и другие сообщения.

### Цикл обработки сообщений

| Функция | Действие |
|---|---|
| `GetMessage` | Извлекает сообщение из очереди потока. **Ждёт**, если очередь пуста. Для `WM_QUIT` возвращает 0 |
| `PeekMessage` | Проверяет очередь **без ожидания** (игры, фоновая работа) |
| `TranslateMessage` | Преобразует сообщения клавиш (`WM_KEYDOWN`) в символьные (`WM_CHAR`) |
| `DispatchMessage` | Вызывает оконную процедуру окна-получателя |

### Оконная процедура

- Сигнатура: `LRESULT CALLBACK WndProc(HWND, UINT, WPARAM, LPARAM)`.
- Обрабатывает нужные сообщения и возвращает результат (обычно 0).
- Всё остальное передаёт в **`DefWindowProc`**: перемещение окна, изменение размера, системное меню, рамка.
- Вызывается **системой**, а не программой. Поэтому функцию называют «функцией обратного вызова» (callback).

## Понятие оконного сообщения

```c
typedef struct tagMSG {
    HWND   hwnd;     // окно-получатель
    UINT   message;  // идентификатор сообщения: WM_PAINT, WM_KEYDOWN...
    WPARAM wParam;   // параметр 1 (код клавиши, идентификатор команды)
    LPARAM lParam;   // параметр 2 (координаты, флаги, указатель)
    DWORD  time;     // время помещения в очередь
    POINT  pt;       // положение курсора в этот момент
} MSG;
```

### Основные сообщения

| Сообщение | Когда приходит |
|---|---|
| `WM_CREATE` | Окно создаётся (до показа) |
| `WM_PAINT` | Нужно перерисовать клиентскую область |
| `WM_SIZE`, `WM_MOVE` | Изменился размер или положение |
| `WM_COMMAND` | Выбран пункт меню, нажата кнопка, горячая клавиша |
| `WM_NOTIFY` | Уведомление от сложного элемента управления |
| `WM_KEYDOWN`, `WM_CHAR` | Клавиатура ([вопрос 26]({{ '/q/26.html' | relative_url }})) |
| `WM_MOUSEMOVE`, `WM_LBUTTONDOWN` | Мышь |
| `WM_TIMER` | Сработал таймер `SetTimer` |
| `WM_CLOSE` | Пользователь закрывает окно (можно отменить) |
| `WM_DESTROY` | Окно уничтожается |
| `WM_QUIT` | Завершить цикл сообщений (окну не передаётся) |
| `WM_USER + n`, `RegisterWindowMessage` | Собственные сообщения программы |

## Источники сообщений

<pre class="diagram">
 Клавиатура, мышь ─► драйверы ─► системная
                                очередь ввода
                                    │ RIT
                                    ▼
 Таймер, система ─────────► Очередь потока ─► GetMessage
 PostMessage (другие окна) ─►     │
                                  ▼
 SendMessage ──────────────────► WndProc (напрямую)
</pre>

1. **Пользователь (аппаратный ввод):** клавиатура и мышь. Драйвер помещает событие в **системную очередь ввода**. Поток необработанного ввода (**RIT**) в win32k.sys определяет окно-получатель (окно с фокусом или под курсором) и переносит сообщение в очередь его потока.
2. **Система (ОС и оконный менеджер):** `WM_CREATE`, `WM_SIZE`, `WM_PAINT` (по региону обновления), `WM_TIMER`, `WM_QUERYENDSESSION` (завершение работы), `WM_DEVICECHANGE`, `WM_POWERBROADCAST`.
3. **Другие программы и окна:**
   - `SendMessage` — **синхронно**: вызывает оконную процедуру и ждёт результата;
   - `PostMessage` — **асинхронно**: ставит сообщение в очередь и сразу возвращается;
   - широковещательная рассылка `HWND_BROADCAST`.
4. **Сама программа:** `PostQuitMessage`, `InvalidateRect` (запрос перерисовки), собственные `WM_USER`.
5. **Элементы управления:** кнопки и поля ввода сообщают родительскому окну о событиях через `WM_COMMAND` (`BN_CLICKED`, `EN_CHANGE`) и `WM_NOTIFY`.

**Ставятся ли в очередь:**
- через очередь (**queued**) проходят ввод, `WM_PAINT`, `WM_TIMER`, `WM_QUIT`, `PostMessage`;
- напрямую (**nonqueued**) идут `SendMessage`, `WM_CREATE`, `WM_SIZE`, `WM_ACTIVATE` и другие уведомления.
