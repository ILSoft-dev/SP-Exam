# Системное программирование: пособие к экзамену

Пособие для подготовки к экзамену по дисциплине «Системное программирование» (специальность переподготовки 1-40 01 73 «Программное обеспечение информационных систем»). Сайт адаптирован для просмотра с телефона.

**Сайт:** https://inikonoff.github.io/SP-Exam/

## Что внутри

- **40 экзаменационных вопросов** (`q/01.md` … `q/40.md`) с примерами кода на C (WinAPI и POSIX). Каждый ответ начинается с блока «Коротко для ответа» и заканчивается вопросами для самопроверки. Вопросы 16 и 17 в программе повторяют 2 и 3 — на их страницах выжимка и ссылка.
- **Тест для самопроверки** (`quiz.md`, банк вопросов в `assets/quiz-data.js`).
- **Шпаргалка по WinAPI и системным вызовам Linux** (`api.md`) с таблицами соответствия.
- **Глоссарий** (`glossary.md`).

Функции для телефона: оглавление в выдвижной панели, светлая и тёмная тема, изменение размера шрифта, отметки «выучено» с прогрессом на главной (хранятся в браузере), поиск по вопросам и терминам.

## Публикация на GitHub Pages

1. **Settings → Pages**.
2. **Source:** *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту-две сайт будет доступен по адресу `https://<владелец>.github.io/SP-Exam/`.

GitHub Pages сам собирает сайт с помощью Jekyll. Если репозиторий переименуют, поменяйте `baseurl` в `_config.yml`.

## Локальный просмотр

```bash
gem install jekyll kramdown-parser-gfm
jekyll serve
# открыть http://localhost:4000/SP-Exam/
```
